# Ilustrații locale AutoHunter DEMO

**Arhivă de etapă:** aceste trei ilustrații nu mai sunt importate sau afișate în aplicație.
Au fost înlocuite de suportul pentru fotografii per anunț din `fixtures/images`.
Textul de mai jos documentează proveniența implementării anterioare.

Fișiere: cars.png, tractors.png, tools.png. Create pentru proiect pe 25 octombrie 2026
cu instrumentul integrat image_gen, în modul generate, fără imagini de referință.
Nu sunt fotografii ale anunțurilor, nu provin de pe OLX și nu reprezintă modele,
mărci sau produse reale oferite spre vânzare. Fiecare imagine reprezintă o categorie;
ilustrația pentru scule nu promite că obiectele desenate sunt incluse într-un anunț.

Componenta ListingImage afișează obligatoriu textul:
„DEMO · Ilustrație de categorie, nu fotografia produsului”.
Fișierele sunt incluse de Metro în exporturile web și Android. Nu necesită internet.
Nu pretindem o licență terță sau exclusivitate asupra imaginilor generate.
